# بُنيان — النشر والربط السحابي

## GitHub Pages

ملف .github/workflows/deploy-pages.yml في جذر المشروع ينشر محتويات مجلد outputs تلقائياً إلى GitHub Pages عند الدفع إلى فرع main. فعّل Pages من إعدادات المستودع مع Source: GitHub Actions.

## Google Sheets

انسخ ملفات apps-script إلى مشروع Apps Script ونفّذ خطوات دليل الإعداد في apps-script/README.md. بعد نشر Web App، الصق رابط /exec في إعداد الاتصال بشاشة تسجيل الدخول. في أول دخول أنشئ حساب المدير باستخدام رمز التهيئة الذي يظهر في سجل تنفيذ Apps Script.

## ما الذي يتزامن؟

عند استخدام رابط API، تُحمّل صفحات النظام بياناتها من Google Sheets قبل العرض، وتُرسل التعديلات إليها. كما تُسجل موافقة العميل والتوقيع الإلكتروني مباشرة في قاعدة البيانات. صفحة مراجعة العميل عامة وتعمل برابط العرض؛ لا يحتاج العميل إلى حساب في النظام.

## ملفات الواجهة

الصفحات والأنماط والسكريبتات وملف Service Worker كلها داخل هذا المجلد. ارفع الملفات كما هي؛ لا تغيّر مسارات الصفحات.
